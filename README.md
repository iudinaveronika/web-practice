# Учебный проект: Git, JS и Google Таблицы

## Отчёт об использовании ИИ (Задание 3)

* **Использованный инструмент:** Gemini / ChatGPT.
* **Заданный промпт:** 
  > «Напиши JavaScript-код, который с помощью fetch() загружает данные из опубликованной в формате CSV Google Таблицы и выводит их на веб-страницу в виде HTML-таблицы внутри элемента с id="table-container".»

### Исходный код, сгенерированный ИИ:
```javascript
fetch('URL_ТАБЛИЦЫ')
  .then(res => res.text())
  .then(data => {
    const rows = data.split('\n');
    let html = '<table>';
    rows.forEach(row => {
      html += '<tr>';
      row.split(',').forEach(col => html += `<td>${col}</td>`);
      html += '</tr>';
    });
    html += '</table>';
    document.getElementById('table-container').innerHTML = html;
  });
```

### Что ИИ сделал правильно, а что пришлось исправить:
1. **Что сделано верно:** ИИ правильно применил метод `fetch()` для получения текстового ответа (`res.text()`) и разбил CSV-строку по переносам строк (`\n`) и запятым (`,`).
2. **Обнаруженные ошибки и доработки:**
   * **Отсутствие обработки ошибок:** В коде ИИ не было проверки `response.ok` и блока `try/catch`. Если ссылка на таблицу окажется неверной или доступ закроют, скрипт упадёт в консоли, а пользователь останется с надписью «Загрузка...».
   * **Проблема с переносами строк (`\r`):** Google Таблицы при экспорте в CSV используют формат переноса `\r\n`, из-за чего оставался невидимый символ возврата каретки. Я добавила `.replace(/\r/g, '')`.
   * **Заголовки таблицы:** ИИ оборачивал все строки в теги `<td>`. Я переписала логику так, чтобы первая строка (`index === 0`) рендерилась через теги заголовков `<th>`.
   * **Безопасность (XSS):** Вместо вставки сырого HTML через `innerHTML` я использовала безопасное создание элементов через `document.createElement` и `textContent`.

В процессе работы я научилась связывать веб-страницу с Google Таблицами без серверного бэкенда, работать с ветками и Pull Request в Git, а также проверять код нейросети на наличие ошибок сети и краевых случаев.
